# Gifsicle Go

This is a Go binding for the [Gifsicle](https://www.lcdf.org/gifsicle/) CLI tool.

It allows you to perform the same operations you can using `gifsicle` but from inside Go without have to spawn commands outside.

This version is mostly focused on Gif optimization. Future releases might include more manipulation options.

## Disclaimer

This repository was written using LLM models while still being supervised by a human.
